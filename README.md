# ДоброВет — сайт ветклиники (Нижнекамск)

Одностраничный сайт районной ветеринарной клиники.
Чистый HTML + CSS + JS, без сборки и без npm. Единственная внешняя
зависимость — GSAP с CDN и шрифты Google (Unbounded + Onest).

**Это прототип.** Страница закрыта от индексации (`noindex`) и содержит
временные материалы — см. «Что заменить перед запуском».

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Структура

```
index.html            единственная страница
styles/tokens.css     токены: палитра с проверенным контрастом, шкалы
styles/main.css       раскладка и компоненты
scripts/config.js     график работы клиники (единственное место)
scripts/main.js       статус «открыто/закрыто», GSAP-анимации, чек-лист
assets/photos/        рабочие WebP
assets/brand/         логотип и фавиконки
```

Документация проекта: `CLAUDE.md` (правила), `CONTENT.md` (весь текст и
что ещё не подтверждено), `DOBROVET-BRIEF.md` (бизнес), `PHOTO-PLAN.md`
(какие кадры снять), `.tastemaker/style-lock.md` (дизайн-система).
