# ДоброВет — сайт ветклиники (Нижнекамск)

Одностраничный сайт районной ветклиники. Русский язык, mobile-first.
Сайта у клиники сейчас нет — собираем с нуля.

**Статус: первая попытка дизайна забракована владельцем и удалена целиком.**
Стиль пересобран заново по референсам владельца (`references/`). Код сайта
(index.html, styles/, scripts/, assets/) удалён — верстаем с чистого листа
по новой системе.

## Прочитать перед первой строкой кода

| Файл | Что в нём |
| --- | --- |
| `.tastemaker/style-lock.md` | **Главный документ стиля.** Палитра с проверенным контраст-контрактом, типографика, шкалы, структура, список «не переносить». Выведен из референсов, не выдуман. |
| `references/` | Пять референсов владельца — исходник стиля. Смотреть глазами, а не пересказывать по памяти. |
| `style-specimen.html` | Живой образец: палитра, контрастные пары, три варианта дисплейного шрифта на реальных русских заголовках. |
| `CONTENT.md` | Весь текст сайта + таблица неподтверждённых данных. Единственный источник копирайта. |
| `DOBROVET-BRIEF.md` | Бизнес: позиционирование, аудитория, услуги, конкуренты, SEO. |
| `PHOTO-PLAN.md` | Какие реальные кадры нужно получить от клиники (маппинг на секции — от старой структуры, перепривязать). |

## Стек — зафиксирован, не обсуждается

- **Чистый HTML + CSS + JS. Без фреймворка, без сборки, без npm.**
  Это лендинг районной клиники: он должен открываться за секунду на 4G с телефона
  у человека в панике. React/Next здесь — лишний вес и лишний риск.
- **Без Tailwind.** Токены живут в `styles/tokens.css` как CSS-переменные.
  Tailwind провоцирует произвольные значения (`p-[17px]`), а система требует строгой шкалы.
- **GSAP + ScrollTrigger с CDN** — единственная внешняя зависимость.
- **Google Fonts:** Onest (текст) + дисплейный шрифт по выбору владельца,
  обязательно `preconnect`, подмножество `cyrillic,latin`.
  Кириллицу у любого нового шрифта проверять запросом к Google Fonts, а не по памяти —
  каталожные Urbanist и Archivo кириллицы не имеют.
- Превью: `python3 -m http.server 8000` в корне.

### Карта файлов (создаётся заново)

```

styles/tokens.css     токены из style-lock.md — контраст пересчитывать при любом новом оттенке

assets/photos/        фото: сгенерированные плейсхолдеры → потом реальные съёмки

assets/icons/         иконки, одно семейство
```

## Жёсткие правила

1. **Ни одного инлайнового цвета.** Только `var(--token)`. Нужен новый оттенок —
   сначала посчитать контраст (`check_contrast.py`), потом добавить в `tokens.css`
   и в контракт `style-lock.md`.
2. **Ни одного отступа вне шкалы.** `padding: 17px` — ошибка.
3. **Никаких градиентов.** Ни в фоне, ни в кнопке, ни в тексте. В референсах они есть —
   это как раз то, что не переносим.
4. **Никаких трёх одинаковых карточек услуг** и никакого футера из четырёх колонок.
5. **Никаких эмодзи вместо иконок, никаких лапок и косточек как декора.**
   Лапки фоном есть в одном из референсов — не переносить, это штамп категории.
6. **Фото: на этапе прототипа генерируем всё** — решение владельца от 2026-08-26.
   Животные, интерьеры, кадры приёма. Стока по-прежнему нет.
   Два условия, без которых генерация становится ложью на живом сайте:
   - оригиналы лежат в `assets/photos/_placeholder/`, рабочие WebP — в `assets/photos/`,
     и каждая картинка помечена атрибутом `data-placeholder`.
     **Метка идёт в `data-placeholder`, а не в `alt`:** `alt` читают скринридеры
     живым посетителям, и слово «плейсхолдер» там — мусор в ухо. В `alt` —
     нормальное описание кадра, метка — для того, кто правит код;
   - **перед публикацией все до одного заменяются реальными кадрами** по `PHOTO-PLAN.md`;
     под врачами имена не подставляем — там `—` и «уточняется», как в `CONTENT.md`.
   Сильнейший приём референсов — животное, вырезанное по контуру, поверх типографики.
   На него тратим больше всего усилий.
7. **`transition: all` запрещён.** Анимировать только `transform` и `opacity`.
8. **НИ ОДНОЙ ВЫДУМАННОЙ ЦИФРЫ.** Рейтинг, стаж, число врачей, количество пациентов,
   цены, имена врачей — либо из `CONTENT.md` с пометкой «подтверждено»,
   либо на сайте стоит `—` и подпись «уточняется». Правдоподобное число, которого
   никто не подтверждал, — это ложь на сайте медицинской услуги.
   Во всех референсах есть строка метрик — у нас её нет и не будет, пока не придут данные.
9. **Один намеренный слом сетки** — вырезанное животное перекрывает дисплейный
   заголовок в hero. Ровно один, второй не добавлять.
10. **Лайм — только заливка.** Текстом на светлом фоне он даёт контраст 1.31 и исчезает.

## Готово — это когда

- Нет горизонтального скролла на ширинах 320 / 375 / 768 / 1280 / 1920.
- Телефоны кликабельны (`tel:`), цели нажатия на мобильном ≥44px.
- Работает `prefers-reduced-motion`.
- Каждая цветовая пара на странице есть в контракте `style-lock.md`.
- Lighthouse: производительность ≥90 на мобильном эмуляторе, доступность ≥95.
- В коде не осталось ни одного `TODO`, который не отражён в `CONTENT.md`.

## Что делать с недостающими данными

Не выдумывать и не откладывать молча. Порядок:
1. Сверстать секцию полностью, с правильной раскладкой и типографикой.
2. На месте неподтверждённых значений — `—` и подпись «уточняется».
3. Добавить строку в раздел «Ожидает данных» в `CONTENT.md`.
4. В конце работы перечислить пользователю, что именно нужно запросить у клиники.
